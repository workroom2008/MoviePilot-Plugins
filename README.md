## 插件说明

### 企业微信可信IP助手

企业微信应用需要把调用方公网 IP 加入「可信IP」白名单，家宽 / 移动网络的 IP 会变动，手工维护很麻烦。本插件定时检测公网 IP，一旦变化就自动写入所有配置过的应用。

相对社区同类实现的改进：

- **IP 识别**：只使用 IPv4 专用接口，并用 `ipaddress` 做地址合法性校验，过滤私网 / 回环 / 保留地址。避免拿到 IPv6、或把版本号误当 IP。
- **低 CPU 保活**：先发一次普通 HTTP 请求判断登录态，同时把响应里的 `Set-Cookie` 合并回本地实现续期。只有探活失败才启动 Chromium 复核，把常态保活从「每次启动浏览器」降到「一次 HTTP 请求」。
- **不会漏同步**：登录态失效时不再静默跳过，而是记录待同步标记；恢复后自动补写。
- **写入后回读校验**：每个应用写完后重新打开弹窗读回，确认真的写进去了。
- **状态仪表盘**：详情页直接展示当前 IP、登录态、同步结果与明细。

#### 配置说明

| 配置项 | 说明 |
|--------|------|
| 启用插件 | 总开关 |
| 立即检测一次 | 保存后立刻跑一次检测 |
| 发送通知 | 是否推送企业微信通知 |
| 覆盖已有IP | 开：直接覆写；关：按分号追加 |
| 从 CookieCloud 获取 Cookie | 从 CookieCloud 拉取企业微信 Cookie |
| 应用地址 | **必填**，多个用英文逗号分隔 |
| Cookie 失效后自动登录 | 失效后自动进入扫码登录流程 |
| IP 检测周期 | 默认 `*/11 * * * *` |
| Cookie 保活周期 | 默认 `*/5 * * * *` |
| 失效通知周期 | 关闭自动登录时生效，默认 `0 * * * *` |
| HTTP / 浏览器超时 | 默认 15 / 180 秒 |
| 手动 Cookie | 非必填，HeaderString 格式 |
| 接收二维码成员ID | 非必填，留空发给全部成员 |
| 自定义 IP 源 | 非必填，留空用内置源 |

内置 IP 源：`ddns.oray.com/checkip`、`ipv4.icanhazip.com`、`v4.ipip.net`、`ipinfo.io/ip`。

#### 使用提示

- 登录态失效后，向 MoviePilot 应用回复 `#登录企业微信` 重新扫码。
- 若登录要求手机验证，按 `#123456` 格式回复验证码。
