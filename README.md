## 插件说明

### 企业微信可信IP守护

企业微信应用需要把调用方公网 IP 加入「可信IP」白名单，家宽/移动网络 IP 会变动，手工维护很麻烦。本插件定时检测公网 IP 并在变化时自动写入。

相对社区同类实现的改进：

- **IP 识别**：只使用 IPv4 专用接口，并用 `ipaddress` 做地址合法性校验，过滤私网/回环/保留地址。避免了拿到 IPv6、或把版本号误当 IP 的问题。
- **Cookie 保活**：先发一次普通 HTTP 请求判断登录态，同时把响应里的 `Set-Cookie` 合并回本地实现续期。只有探活失败才启动 Chromium 复核，把常态保活从「每 5 分钟启动一次浏览器」降到「一次 HTTP 请求」，CPU 占用接近 0。
- **不会漏同步**：cookie 失效时不再静默跳过，而是记录待同步标记；cookie 恢复后自动补写。
- **可观测**：插件页面直接展示当前 IP、IP 来源、检测时间、Cookie 状态、同步结果与每个应用的写入明细。
- **可配置**：IP 检测周期、Cookie 保活周期、IP 源、HTTP/浏览器超时、是否覆盖已有 IP、是否自动登录等均可配置。

#### 配置说明

| 配置项 | 说明 |
|--------|------|
| 启用插件 | 总开关 |
| 立即检测一次 | 保存后立刻跑一次检测 |
| 发送通知 | 是否推送企业微信通知 |
| 覆盖模式 | 开：直接覆写可信IP；关：按分号追加 |
| 使用CookieCloud | 从 CookieCloud 拉取企业微信 cookie |
| Cookie失效自动登录 | 失效后自动进入扫码登录流程 |
| 调试日志 | 输出更详细的排查信息 |
| IP检测周期 | 默认 `*/11 * * * *` |
| Cookie保活周期 | 默认 `*/5 * * * *` |
| 失效通知周期 | 关闭自动登录时生效，默认 `0 * * * *` |
| HTTP超时 | 单次 HTTP 请求超时秒数，默认 15 |
| 浏览器超时 | 浏览器操作超时秒数，默认 180 |
| 企业微信应用管理网址 | 必填，多个用英文逗号分隔 |
| 手动 Cookie | 非必填，HeaderString 格式 |
| 自定义IP源 | 非必填，逗号分隔，留空用内置源 |
| 接收二维码成员ID | 非必填，留空发给全部成员 |

#### 使用提示

- Cookie 失效后，向 MoviePilot 应用回复 `#登录企业微信` 可重新扫码。
- 若登录要求手机验证，按 `#123456` 格式回复验证码。
- 内置 IP 源：`ddns.oray.com/checkip`、`ipv4.icanhazip.com`、`v4.ipip.net`、`ipinfo.io/ip`。
